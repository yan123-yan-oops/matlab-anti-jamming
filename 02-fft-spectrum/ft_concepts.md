# FT / FFT 概念深度解析

> 这是你学 **02-fft-spectrum** 时最容易卡住的概念。
> 我们不说数学公式，用"感觉"来理解它。

---

## 1. FT（傅里叶变换）在干什么？

```
你听到一首歌 → 你的耳朵在干的事就是傅里叶变换
                ↓
你把"一整段声音"拆成了"什么乐器在什么时候用多大声音"
                ↓
                FT 就是把混合信号拆成一个个单一频率
```

**一句话**：FT = 把信号从"随时间变化"翻译成"随频率变化"。

| 域 | 横轴 | 看的什么 |
|----|------|----------|
| 时域 | 时间 (s) | 信号怎么随时间变 |
| 频域 | 频率 (Hz) | 信号里有哪些频率成分 |

---

## 2. FFT（快速傅里叶变换）不是另一种变换

**FFT 就是 FT 的"快速算法"**，就像乘法分配律比一个个加要快一样：

```
FT 的计算量：N² 次运算
FFT 的计算量：N·log₂(N) 次运算

N = 1024 时：
  FT  ≈ 1,000,000 次
  FFT ≈ 10,000 次  ← 快 100 倍！
```

**FFT 要求输入长度是 2 的幂**（64、128、256、512、1024...），
和 C 里环形缓冲区为什么要是 2 的幂是**同一个原因**——可以用位运算代替取模。

---

## 3. 采样率、点数、频率分辨率三者的关系

```
频率分辨率 = 采样率 / FFT点数

例：Fs = 1000Hz, N = 1000 点
  分辨率 = 1000/1000 = 1 Hz → 能区分 10Hz 和 11Hz
  
例：Fs = 1000Hz, N = 100 点
  分辨率 = 1000/100 = 10 Hz → 只能区分 10Hz 和 20Hz
```

**怎么提高分辨率？**
- 增加采样时长（采更多点）→ FFT 点数增大 → 分辨率提高 ✨

---

## 4. 频谱泄露 —— 为什么谱线会"糊掉"

```
你切了一小段信号来做 FFT
                ↓
             这相当于"突然开始、突然结束"
                ↓
            信号被"截断"了 → 能量扩散到旁边频率
                ↓
              这就是频谱泄露
```

**加窗 = 让开始和结束不那么突然**（像音量渐入渐出）

| 窗函数 | 主瓣宽度 | 旁瓣高度 | 适合场景 |
|--------|----------|----------|----------|
| 矩形（不加窗） | 最窄 | 最高 | 要求分辨率 |
| 汉宁 (hann) | 中等 | 低 | 通用推荐 |
| 布莱克曼 | 最宽 | 最低 | 要求抑制噪声 |

## 5. 和 C 指针的联系（对应你的学习路线）

| C 指针概念 | MATLAB FFT 概念 | 共同点 |
|-----------|----------------|--------|
| `arr[i]` = 取第 i 个元素 | `X(k)` = 第 k 个频率分量 | 都是索引偏移 |
| `arr + 1` 跳过一个元素大小 | `k+1` 跳过一个频率分辨率 | 间隔由元素大小/分辨率决定 |
| 数组长度 = 分配的内存大小 | FFT 点数 = 频率分辨率 | 决定了你能"看到"多少东西 |

## 6. 常见困惑速查

| 困惑 | 答案 |
|------|------|
| FFT 结果为什么对称？ | 实信号的频谱是共轭对称的，只看前一半即可 |
| 横轴是 0~Fs？还是 -Fs/2~Fs/2？ | 都行，`fftshift` 把 0 频移到中间 |
| 幅度怎么算？ | `abs(X)/N*2`（单边谱，除直流外都 ×2） |
| 相位怎么看？ | `angle(X)`，但实际工程很少看相位 |
| 补零能提高分辨率吗？ | ❌ 不能！补零只是插值，真正的分辨率由采样时长决定 |

## 7. 高频疑问详解（动手时问出来的问题）

### 7.1 为什么 `abs(X)/N*2` 是"幅度"、下标换成 `f` 才是"频率轴"？

`X = fft(x)` 输出的是一串**复数**。复数有两种读法：

| 读法 | MATLAB | 含义 |
|------|--------|------|
| 实部 / 虚部 | `real(X)` / `imag(X)` | 数学上的原始形态 |
| **模长 / 辐角** | `abs(X)` / `angle(X)` | 该频率分量的**大小 / 相位** |

所以 `abs(X)` 取模这一步，天然得到的就是"幅度谱"（相位谱工程上很少看）。

但 `X(11)` 里的 11 是**数组下标，不是 Hz**，它表示"第 10 号频率格子"。换算成物理频率：

```
f_k = k × Fs / N        (k = 0, 1, 2, ..., N-1)
```

代码里就是 `f = (0:N-1) * Fs / N`。

**C 地址类比**：

```
addr = base + k * stride      // 指针：第 k 个元素在哪个地址
f    = 0    + k * (Fs/N)      // 频率：第 k 个格子是多少 Hz
```

`Fs/N` 就是步长 stride，即**频率分辨率**（= 1/T，T 是采样总时长）。
例：Fs = 1000, N = 1000 → 每格 1 Hz → 格子落在 0, 1, 2, ..., 10, ..., 50, ... Hz。

**为什么除以 N 再乘 2？**

| 操作 | 原因 |
|------|------|
| `/N` | FFT 把 N 个采样点**累加**了，N 越大数值越大；除以 N 才还原真实幅度（同 C 的 `sum/count`）|
| `×2` | 实正弦的能量**对称分成两半**：+10Hz 一半、-10Hz（即 990Hz）一半。只画正频率半边，就把丢掉的一半补回来 → 单边谱 |

数值验证：`sin(2π·10t)` 振幅为 1 → `|X(11)| = N/2 = 500` → `mag(11) = 500/1000×2 = 1.0` ✔

```matlab
% 在命令行验证
mag(11)   % 1.0000  ← 10Hz 分量振幅
mag(51)   % 0.5000  ← 50Hz 分量振幅（第二个实验）
```

> ⚠️ 严格讲直流 0Hz 和奈奎斯特点的格子不能 ×2，但纯正弦里没有这两种成分，不影响。

### 7.2 为什么 10 Hz 正弦的频谱是"一根尖峰"？

要**两个条件同时成立**：

1. **纯正弦只有一个频率成分** —— sin(2π·10t) 里除了 10Hz 什么都没有。
2. **10 Hz 正好踩在格点上** —— 分辨率 1Hz 时 10 是整数格。等价地：1 秒窗口里恰好装了 10 个**完整周期**，首尾接得上、没有截断 → 能量全集中在第 10 号格子。

数学本质是**正交性**：只有与 10Hz 同频的基函数"点乘"信号时内积 = N/2 ≠ 0，其余频率全部为 0。

**反例**：10.5 Hz 不落格点 → 尖峰"摊开"成一片 → **频谱泄露**（`fft_intro.m` 第 4 节）。

**镜像**：实信号频谱共轭对称，990Hz（= -10Hz）处还有一根同样的尖峰，被 `f(1:100)` 截掉没画——这就是 ×2 的物理来源。

### 7.3 茎状图（stem）有什么特点？

- 一根竖直"火柴杆" + 顶点标记 = 一个离散值；**点与点之间没有东西**
- 语义 = **离散序列**：只在离散位置上"有值"。DSP 教材里 δ[n]（单位脉冲）的标准画法就是 stem——"冲击"这个词用得很准
- 与 `plot` 的本质区别：

| | 画法 | 暗示 | 适合 |
|---|---|---|---|
| `plot` | 用线连接数据点 | 两点**之间也有连续的值** | 适用于连续 / 模拟信号 |
| `stem` | 只在点上画竖杆 | 点之间**无定义** | 适用于采样后的离散信号 |

- **FFT 结果必须用 stem**：频谱只有 N 个离散频点有值，用 plot 画会让人误以为 10.5Hz 处也有高度，而那里"不存在数据"
- 常用处：数字序列 x[n]、FFT 频谱 X[k]、单位脉冲响应 h[n]、概率质量函数
- 语法：`stem(x, y)` 在 x 各位置画 y；`stem(y)` 默认 x = 1:length(y)；加 `'filled'` 填充圆点
